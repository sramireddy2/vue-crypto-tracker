# Vue Crypto Tracker

A modern Vue 3 crypto tracker with live data from CoinGecko stream.

## Features
- Responsive card grid with price, icon, 24 h change    
- “Load more” pagination  

## Tech Stack
- Vue 3 + Composition API
- Vite
- Node.js
- Axios for REST  

## Installation
```bash
git clone https://github.com/sramireddy2/vue-crypto-tracker.git
cd vue-crypto-tracker
npm install
npm run dev
